# Week 5 Progress Report: Homing System Integration and Prototype Development

## Overview

Week 5 focused on achieving reliable machine homing, improving system stability, and initiating the first version of the PCB prototyping machine. Persistent limit switch issues were resolved, enabling successful homing using the GRBL firmware. In parallel, a standard PCB schematic for the soldering iron was designed to streamline the assembly process, and the software developed by the software team was validated on the Arduino-based setup.

## Tasks Completed

- Resolved limit switch issues affecting machine operation.
- Successfully implemented and validated the homing cycle with the home position configured at the front-right corner.
- Designed a standardized PCB schematic for the soldering iron to improve manufacturing consistency.
- Created a 3D CAD model of a servo motor in Fusion 360.

## Challenges Faced

- Hard limit alarms were triggered during laser operation due to electrical noise affecting the limit switch signals.
- Homing repeatedly failed during testing and required firmware configuration and troubleshooting within GRBL.
- Encountered connectivity issues while designing the soldering iron PCB schematic, requiring circuit verification and corrections.

## Key Outcomes

- Achieved reliable homing functionality for the CNC machine.
- Improved overall machine stability by resolving limit switch-related issues.
- Standardized the soldering iron PCB design for future production.
- Continued strengthening CAD modeling skills through component design in Fusion 360.

## Next Steps

- Integrate a display interface into the CNC machine for improved user interaction.
- Develop the complete CAD model for the first functional prototype of the PCB prototyping machine.
- Design and manufacture a dedicated PCB for the soldering iron.
